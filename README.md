# 豆豆 PetPal — 虚拟宠物精神陪伴 MVP

一个**手机浏览器直接打开**的虚拟宠物陪伴 App。无需安装、无需后端、离线可用。
这是我们 PRD V2 里 Must Have 范围的可运行实现。

---

## 怎么在手机上打开

**方式一：手机和电脑在同一个 WiFi（推荐，体验最完整）**

1. 在电脑上启动本地服务（项目根目录）：
   ```bash
   cd petpal
   python3 -m http.server 8848
   ```
2. 在电脑上查到局域网 IP（macOS）：`ipconfig getifaddr en0` → 例如 `192.168.68.105`
3. 手机浏览器打开：`http://192.168.68.105:8848/index.html`
4. iOS Safari / Android Chrome 里点「添加到主屏幕」，它会像独立 App 一样全屏运行（PWA）。

**方式二：直接在电脑浏览器体验**
打开 `http://localhost:8848/index.html`，用浏览器开发者工具的手机模拟视图即可。

> 注：用 `file://` 直接双击打开 index.html 大体也能跑（纯前端 + localStorage），
> 但建议用 http 服务，PWA 和部分浏览器特性需要它。

## 这个 MVP 实现了 PRD 里的什么（每条都是真逻辑，不是壳）

| PRD 模块 | 在哪 | 说明 |
|---|---|---|
| 宠物创建 + 真宠数字分身 | `app.js` finishOb / `ui.js` onboarding | 选物种/天性/取名；可上传真宠照片+性格生成分身 |
| **长期记忆系统** | `js/memory.js` | 三卡点全部实现，见下 |
| 情绪状态机 + 最小互动反馈 | `js/emotion.js` + 主页摸/喂/玩 | 6 种情绪状态，随互动和时间变化；动作即时反馈 |
| 主动陪伴消息 | `js/proactive.js` | 有理由、低频(每日≤3)、首条提前到创建后 ~20s（Day0 aha） |
| 关系亲密度（去 KPI 化） | `js/persona.js` | 后台刻度驱动宠物行为/态度，"TA"页可看但不是打卡进度条 |
| 成长事件链（80/20） | `js/events.js` | 8 个事件，~80% 温暖 / ~20% 温和小挫折，需你选择才推进 |
| "睡眠"统一巩固机制 | `ui.js` renderSleep | 一觉跑完：巩固→遗忘→做梦→人格偏移→新的一天 |

### 记忆系统三卡点（核心差异化，`js/memory.js`）
1. **什么值得记**：`salience` 打分（情绪强度/极性/自我袒露/关系事件/明示）；两类(情感/事实)×三期(短/中/长)；情感闪光通道(强情绪直升长期) + 重复强化通道 + 自然衰减遗忘。
2. **自然的想起**：通道A 情境线索召回(时间/情绪/主题，非纯关键词) + 通道B 做梦式随机回放 + 通道C 抑制层(避免尬翻旧账、用户开心时不提负面)。
3. **人格随记忆偏移**：天性内核 + 偏移向量；方向由天性决定(温顺→向内退缩/孤僻→向外对抗)，量由经历强度决定；三道闸：**慢**(每日上限)、**有界**(drift_bounds)、**可解释**(drift_log，"TA"页能看到"它为什么变")。黑化封顶 + 可逆 + 永不向用户。

## 体验建议（重要）

真实产品里记忆沉淀、做梦、人格偏移都随**真实时间**发生。为了让你在几分钟内体验完整闭环，
主页右上角有个 **DEV** 按钮（演示用）：
- 📨 主动消息：立刻收到一条"它在惦记你"
- 🎬 成长事件：触发一个需要你选择的事件
- 🌙 快进到明天：触发"睡觉"，看记忆如何被巩固、它做了什么梦、性格有没有变化

**推荐体验路径**：创建宠物 → 聊几句心里话（说点累/难过/开心的事）→ 主页摸摸喂喂 →
DEV 触发事件并做选择 → DEV 快进睡觉看它做梦 → 多重复几天 → 去"回忆"和"TA"页看它记住了什么、变成了什么样。

## 接真实大模型

对话层 (`js/conversation.js`) 是唯一为离线设计的部分，已预留 LLM 接入点：
`respond()` 已构造好完整 `ctx`（人格/情绪/亲密度/召回的记忆/最近对话），
实现 `llmReply(ctx)` 调你的 `/api/chat` 即可替换离线生成器。记忆/情绪/人格系统全部复用，无需改动。
